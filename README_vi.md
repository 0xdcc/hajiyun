## 📌 Tổng quan

**Hajiyun API (https://hajiyun.top)** là cổng chuyển tiếp API LLM cấp doanh nghiệp dành cho lập trình viên, autonomous agents (Cursor, Claude Code), ứng dụng backend và người dùng SillyTavern.

- **Base URL API**: `https://hajiyun.top/v1`
- **Mô hình hỗ trợ**: `gemini-3.8-flash-high`, `claude-sonnet-4.6`, `claude-opus-4.6`, `gpt-4o`, `deepseek-chat`
- **Ưu điểm**: Không chỉnh sửa prompt, hỗ trợ tắt kiểm duyệt (`BLOCK_NONE`), độ trễ cực thấp với IP dân cư kép, theo dõi uptime 24/7 qua Relay Pulse.
