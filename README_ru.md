## 📌 О проекте

**Hajiyun API (https://hajiyun.top)** — это универсальный шлюз-агрегатор нейросетевых API, разработанный для разработчиков программного обеспечения, задач машинного перевода, интеграции микросервисов и автоматизации рабочих процессов AI.

Платформа предоставляет единый стандартизированный интерфейс, совместимый с форматом OpenAI Chat Completions, с поддержкой нативного стриминга (SSE) и прозрачной тарификации.

Поддерживаются клиенты и среды, позволяющие настраивать собственный Base URL и протокол Chat Completions (включая инструменты разработки, чат-клиенты и рабочие процессы). Фактическая совместимость зависит от реализации конкретного клиента и требует предварительного тестирования:

- **API Base URL**: `https://hajiyun.top/v1`
- **Полный адрес Chat Completions**: `https://hajiyun.top/v1/chat/completions`
- **Русскоязычный раздел**: `https://hajiyun.top/ru/`

## 🧠 Доступные модели

> **Важное примечание по моделям**:
> Точный список доступных моделей, идентификаторы моделей (Model ID), тарифы и лимиты запросов динамически обновляются. Пожалуйста, ориентируйтесь на актуальные данные в личном кабинете [Hajiyun Console](https://hajiyun.top).

Поддерживаются основные семейства моделей, работающие по протоколу Chat Completions:
- **Anthropic Claude**: актуальные версии уточняйте в консоли управления.
- **Google Gemini**: высокопроизводительные модели для работы с контекстом и мультимодальностью.
- **OpenAI**: стандартные модели рассуждений и диалога.
- **DeepSeek**: эффективные модели логических рассуждений.

## 💻 Пример подключения (cURL)

```bash
curl https://hajiyun.top/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ***" \
  -d '{
    "model": "YOUR_MODEL_ID_FROM_CONSOLE",
    "messages": [
      {"role": "user", "content": "Привет, Hajiyun!"}
    ],
    "stream": true
  }'
```

### Настройка сторонних клиентов
Для клиентов с поддержкой пользовательского Base URL:
- **Base URL**: `https://hajiyun.top/v1`
- **API Key**: ключ из личного кабинета Hajiyun
- **Model ID**: актуальный идентификатор модели из консоли
*Примечание: совместимость функций зависит от конкретного клиента.*

## ❓ Часто задаваемые вопросы (FAQ)

#### Как обрабатываются данные запросов и промпты?
Обработка и передача данных осуществляются в соответствии с опубликованными условиями использования и политикой конфиденциальности. Соединение защищено шифрованием TLS.

#### Совместим ли шлюз со всеми методами OpenAI API?
Основной поддерживаемый протокол — **OpenAI Chat Completions** (`/v1/chat/completions`). Специфические методы (Realtime API, Assistants) требуют предварительной индивидуальной проверки.

#### Гарантируется ли полное отсутствие ошибок 429 или строгий SLA?
Ни один сторонний шлюз не может гарантировать 100% непрерывную работу без ограничений по частоте запросов (429). В клиентских приложениях рекомендуется настраивать таймауты и повторные попытки (retry).

#### Является ли сервис официальным продуктом Google или OpenAI?
Нет, Hajiyun является независимым сторонним шлюзом. Упоминание сторонних моделей не означает официального партнерства или сертификации бенчмарками со стороны Google, Anthropic или OpenAI.
