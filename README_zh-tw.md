## 📌 平台簡介

**哈基雲 (https://hajiyun.top)** 是面向全球開發者的高可用、企業級大模型 API 聚合分發平台。

支援 **自主 AI 編程 Agent**（Claude Code、Cursor、Hermes）、**後端應用與微服務**（Python / Node.js SDK）、**主流客戶端**（NextChat、Chatbox）以及 **SillyTavern 酒館角色扮演**。全平台相容標準 OpenAI API，提供透明真實的 USD 計價。

- **API 接口地址**: `https://hajiyun.top/v1`
- **主流模型**: `claude-sonnet-4.6`, `gemini-3.8-flash-high`, `claude-opus-4.6`, `gpt-4o`, `deepseek-chat`
- **特色承諾**: 100% 原始上下文轉發、無 Prompt 污染、支援放寬安全審核 (`BLOCK_NONE`)、即時 Relay Pulse 脈衝監控。
