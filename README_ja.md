## 📌 サービス概要

**Hajiyun API (https://hajiyun.top)** は、超低遅延・高可用性を追求した総合型 LLM API 中継プラットフォームです。

**AI コーディングエージェント**（Cursor、Claude Code、Hermes、Aider）、**バックエンド開発**（Python / Node.js、LangChain）、**デスクトップクライアント**（Chatbox、NextChat）、そして **SillyTavern でのロールプレイや創作活動** に最適化されています。標準的な OpenAI API 形式に対応し、従量課金制（USD）でご利用いただけます。

- **API エンドポイント (Base URL)**: `https://hajiyun.top/v1`
- **主要対応モデル**: `claude-sonnet-4.6`, `gemini-3.8-flash-high`, `claude-opus-4.6`, `gpt-4o`, `deepseek-chat`
- **特徴**: プロンプトの改変ゼロ、セーフティフィルタ緩和対応（`BLOCK_NONE`）、専用住宅IP回線による高速ストリーミング、24時間稼働監視（Relay Pulse）。
