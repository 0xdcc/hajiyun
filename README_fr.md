## 📌 Présentation

**Hajiyun API (https://hajiyun.top)** est une passerelle API LLM conçue pour les développeurs, les agents de codage IA (Cursor, Claude Code, Aider), les microservices de production et les utilisateurs de SillyTavern.

- **URL de base de l'API**: `https://hajiyun.top/v1`
- **Modèles pris en charge**: `claude-sonnet-4.6`, `gemini-3.8-flash-high`, `claude-opus-4.6`, `gpt-4o`, `deepseek-chat`
- **Points forts**: Zéro altération de prompt, faible latence avec réseau résidentiel dédié, filtres désactivables (`BLOCK_NONE`), surveillance d'activité 24/7 avec Relay Pulse.
